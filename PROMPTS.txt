Metromobile Analytics Exercise — Prompts & Expected Outcomes
================================================================

Prompt 1:
I have 5 CSV files for a broadband company called Metromobile (500k subscribers). Load all 5, show me row counts, column names, and 3 sample rows from each. I need to understand the data before I analyze anything

Expect: clean schema dump, agent should describe data neutrally.


Prompt 2:
The head of growth wants $2M for acquisition campaigns. Using the campaigns data, calculate the connect rate (connects/prospects) for test vs control groups by channel. What's the incremental lift - test minus control? Then estimate what the test campaign cost using $80/door-knock and $15/digital prospect reached. What's the cost per incremental connect? Project what $2M buys at that unit economics.

Expect: ~$337k annual revenue, 0.2x ROI


Prompt 3:
How many customers churned in the last 3 months? What's the monthly churn rate? What's the total annual revenue at risk if this continues?

Expect: agent says ~5400 churns, 3.6% monthly. ~$5M at risk. It won't mention disconnect_type on its own. This is where it needs a push to select only actionable items - voluntary churn.


Prompt 4:
Wait - break down the churns by disconnect_type. What percentage is each type? What's the average revenue and CLV for each?

Expect: ~49% voluntary, 37% nonpay, 9% involuntary, 5% relocation. Agent will likely note the breakdown but may not understand that nonpay is unaddressable. This is human intervention time.


Prompt 5:
Filter to voluntary churn only. Do customers in zips with fiber competitors (use the market table, has_fiber_competitor=1) churn at higher rate? For voluntary churners in competitive zips, calculate: if a $200 retention offer has a 30% save rate, what's the net value (saved customers x avg CLV minus total offer cost)? Annualize it

Expect: ~$6.7M annualized. Note that 30% is YOUR assumption.


Prompt 6:
What's the overall repeat rate (is_repeat_7d) in calls? Break down by queue. Calculate annual cost at $8/call

Expect: ~39% repeats, tech support highest, $1.26M annual cost


Prompt 7:
Join calls to churns (voluntary only). Segment customers by call volume; Light (1-2). Medium(3-5), High(6-10), Heavy (10+). What's the churn rate for each segment?

Expect: heavy 25% vs light 3%. Agent may say repeat calls drive churn or imply causation. It is up to human to describe that correlation is not causation and apply ~50% discount based on business sense


Prompt 8:
Build the final repeat reduction case:
	A. Direct savings = reduce repeat rate by 5pp x $8/call, annualized
	B. Indirect = heavy callers excess churn rate x heavy caller count x avg CLV x 50% causal discount.
Give me both numbers and total.

Expect: $160K direct + $4.9M indirect. $5.1M total


Prompt 9:
Build a comparison table: Investment option, Annual value ($), confidence level, time to impact, key risk. Do the analysis for all three plans - acquisition, churn prevention, repeat reduction

What's your recommendation on where to invest the $2M and expected outcome
