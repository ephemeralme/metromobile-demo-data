# /recap

Summarize the most recent analysis or chat thread for a leadership audience.

Output exactly this structure:

**Question:** _one line — what the user asked_

**Answer:** _one or two sentences — the headline number and direction_

**Why we believe it:** _two or three bullets — the calculations or filters that produced the answer_

**What to verify before deciding:** _one or two bullets — the biggest assumptions, the data limit, or a quick stress test the user should run_

Tone: direct, quantitative, no filler. No "I hope this helps" closings. No restating the prompt.
